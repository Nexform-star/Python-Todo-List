# Python Todo List

A simple command-line todo list application written in Python.

## Features

- Add tasks to the list
- Remove tasks from the list
- Display all tasks
- Save tasks in a text file
- Keep tasks between sessions

## Technologies

- Python
- File handling (`.txt`)

## Usage

Run `todo_list.py` with Python and choose an option from the menu.

## Purpose

This project was created to practice Python fundamentals, including lists, conditional statements, loops, and file handling.
